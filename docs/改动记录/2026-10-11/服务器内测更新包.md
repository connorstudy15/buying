# 准备服务器内测更新包

用户要求在域名审核期间先将已融合的新功能更新到服务器。

- 重建前端 dist，服务器不再下载 npm 依赖。
- 增加 `scripts/update_cloud.sh`：独立发布目录、不可变镜像标签、停服后完整备份
  三份数据卷、备份读取和校验和验证、启动检查。保留服务器原有 .env。
- 增加 `scripts/rollback_cloud.sh`：旧镜像配合备份数据恢复到新卷，保留原始卷。
- 更新包排除本机密钥、运行数据库、测试报告和 node_modules。
- 提供中文执行说明 `docs/cloud-update-20261011.md`。

本地前端构建和 Bash 语法检查通过。真实服务器更新及恢复验证尚待用户在
Workbench 执行并反馈，尚未宣布部署完成或公网可访问。
